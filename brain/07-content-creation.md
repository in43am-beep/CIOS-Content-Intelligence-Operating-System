# 07 — CONTENT CREATION (AI Video Production Pipeline)

> Usool: Pipeline fix ho to ek banda roz 1–5 videos nikal sakta hai. Order yaad rakho: **Script → Voice → Assets → Assembly → Packaging → Publish.**

## 1. Pipeline (7 steps)
1. **Research:** File 01 se tested idea uthao.
2. **Script:** File 03 ka system — pehle script, sab kuch uske baad.
3. **Voice:** Narration pehle banao. WPM target ke hisaab se (older audience: 110–130).
4. **Assets:** Character sheets, B-roll list, thumbnail raw material.
5. **Assembly:** Voice ke timestamps pe visuals sync karo (audio-first approach).
6. **Packaging:** Title + thumbnail + description (video se PEHLE finalize).
7. **Publish:** Human approval ke baad hi upload. Phir 48h analytics review.

## 2. Character Consistency (bulk production ki jaan)
- Har main character ki **3-view grey sheet** banao (front, side, 3/4) — ek face per sheet.
- Stable reference: har generation me same reference use karo (`@name` jaisa system).
- **Reject test:** Lighting change karo — agar face badal jaye to sheet fail hai, dobara banao.
- 15-sec video = multiple shots. Har shot ka prompt alag, character reference same.

## 3. Video Prompt Anatomy (kaam karne wala template)
```
[SHOT TYPE: close-up / wide / 3-4 angle]
[SUBJECT: character reference + action + emotion]
[SETTING: location reference, time of day]
[LIGHTING: warm golden hour / soft indoor]
[CAMERA: slow push-in / static / pan left]
[MOOD: tender, hopeful]
[NEGATIVE: no extra fingers, no morphing face, no text]
```
- **Positive locks:** Har prompt me character + style keywords repeat karo.
- **Iterate:** Pehla result 70% ho to reject mat karo — prompt tweak karo, dobara generate karo.

## 4. B-Roll System
- Har video ke liye shot list: har 10–20 sec pe kya dikhega (script ke saath map karo).
- B-roll bank banao: 100+ generic clips (dog running, sunset, hands petting) — dobara use karo.
- **180° rule:** Do characters ke dialogue/reaction me camera ek side pe rakho — viewer confuse nahi hota.

## 5. Bulk SOP (roz 1–5 videos)
- **Batch karo:** Ek din sirf scripts, ek din sirf voices, ek din sirf assembly.
- Template project file: intro/outro, captions style, music bed — har video me reuse.
- **3 human gates:** (1) Script/hook check, (2) visual render check, (3) final publish approval. AI pe andha trust nahi.

## 6. Cost Tiers (10-min video, directional)
- **Budget ($0–2):** Free AI voice + stock footage + CapCut.
- **Mid ($5–15):** Paid voice + AI images + basic AI video shots.
- **Premium ($30–80):** Full AI video generation, custom characters.
- Naye channel ke liye budget tier se shuru karo — packaging aur story pe kharch karo, polish pe nahi.
