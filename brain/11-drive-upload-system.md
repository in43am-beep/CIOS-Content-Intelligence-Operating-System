# 11 — DRIVE UPLOAD SYSTEM (Files ka nizam)

> Usool: 100 videos ke baad wahi jeetta hai jiska **system** hai. Naam aur folders fix — dhoondna 10 second ka kaam.

## 1. Folder Structure (Google Drive)
```
/Channel-Name
  /01-Scripts
  /02-Voiceovers
  /03-Assets (images, B-roll, music)
  /04-Projects (CapCut/Premiere files)
  /05-Finals (upload-ready videos)
  /06-Thumbnails
  /07-Published (upload hone ke baad final yahan move)
  /Branding (file 05 wala folder)
  /Analytics (monthly review sheets)
```

## 2. Naming Convention (sab pe same)
- Format: `V###_short-title_VERSION.ext`
- Misal: `V027_soldier-dog-reunion_FINAL.mp4`, `V027_soldier-dog-reunion_THUMB-v2.png`
- **Kabhi** `final-final-2.mp4` mat rakho. Version number: v1, v2, FINAL.

## 3. Upload Workflow (shoot se publish tak)
1. Script → `/01-Scripts/V###_title.docx`
2. Voice + assets → apne folders me, same V### number.
3. Edit project → `/04-Projects/V###_title/`
4. Export final → `/05-Finals/` (1080p ya 4K, sahi bitrate).
5. Thumbnail → `/06-Thumbnails/` (1280×720, <2MB).
6. **Pre-upload checklist** (neeche) → YouTube pe upload.
7. Publish ke baad final files → `/07-Published/` me move.

## 4. Pre-Upload Checklist
- [ ] Video dekhi? (shuru, beech, aakhir — 3 spots check)
- [ ] Audio saaf? Music voice se neeche?
- [ ] Captions on?
- [ ] Title final (file 09 ka rule)?
- [ ] Thumbnail test pass (zoom-out test)?
- [ ] Description template filled + links kaam karte hain?
- [ ] End screen + cards lage?
- [ ] Playlist select?
- [ ] "Not made for kids" sahi?
- [ ] Schedule time set (audience ke peak hours)?

## 5. Backup Rules
- **2 copies har final ki:** Ek Drive pe, ek external HDD ya alag cloud pe.
- Project files hafte me ek baar sync karo.
- Channel hack ho ya laptop kharab — Drive backup se 1 din me wapas.

## 6. Sharing & Team (baad ke liye)
- Editor ko sirf `/04-Projects` aur `/03-Assets` ka access do — poori Drive nahi.
- Thumbnail designer ko `/06-Thumbnails` ka.
- **Kabhi apna main Google account ka password mat do** — Drive sharing aur YouTube Brand Account roles use karo.
