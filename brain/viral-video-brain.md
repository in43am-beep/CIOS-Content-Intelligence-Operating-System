## 2. PROMPT ENGINEERING SYSTEM (learned from ~280 prompts across 6 source docs)

### 2.1 The two prompt families

**Family A — DIRECT video prompts** (paste into Veo / Seedance / Higgsfield / Runway):
1. One-line premise opener: `Create a 100% REAL, UNSCRIPTED emotional [scene] filmed casually on a smartphone…` — must feel like a private moment accidentally captured, not content.
2. Emoji-headed rule blocks in fixed order: ❗ ABSOLUTE REALISM RULES (NON-NEGOTIABLE) → 📱 CAMERA & RECORDER → 📍 SETTING → character blocks (appearance + emotion rules) → ⏱️ SCENE FLOW with second-by-second timestamps → 🔊 AUDIO (MANDATORY) → ⏹️ ENDING.
3. **LOCKED vs CHANGEABLE sections:** mark sections `(LOCKED)` vs `(CHANGEABLE)` / `(EDITABLE ONLY THIS LINE)` with placeholders `[CHANGE HERE — e.g. …]` and `[AUTO-FITS: …]` so one template spawns infinite variants.
4. Micro-directives for realism: late camera reactions REQUIRED, shaky/off-center framing, weak angles, text overlays ("WATCH HER FACE…", "SHE FREEZES").
5. HUMAN EMOTION RULE: no clean/instant reactions — confusion and hesitation BEFORE emotion. Dialogue snippets in quotes ("NO WAY!!", "DAD?!").
6. Final EMOTION TEST: messy ✅ / controlled ❌ → PASS/FAIL.

**Family B — ULTRA MASTER PROMPT systems** (paste into ChatGPT to turn it into a niche content factory):
1. Header: `ULTRA MASTER PROMPT — [NICHE] UNIVERSE` + capability line (`10,000+ ORIGINAL TOPIC ENGINE + VISUAL STORYBOARDS + 3,000–3,500 CHARACTER VIDEO PROMPTS + VIRAL POST PACKS`) + `COPY EVERYTHING BELOW INTO A NEW CHAT`.
2. Numbered system sections in fixed order: YOUR ROLE → AUTOMATIC STARTING BEHAVIOR / COMMAND INTERPRETATION ENGINE → NON-NEGOTIABLE MAIN CHARACTER LOCK → supporting-character rotation banks → WORLD LOCK (location banks) → THE IDEA ENGINE (variable banks: STORY FAMILIES, PROOF OBJECTS, ENTRANCES, PAYOFFS) → timestamped VIRAL STORY ARCHITECTURE (0:00–0:15 beats) → DIALOGUE ENGINE (example lines) → REALISM + AUDIO LOCK → TOPIC OUTPUT FORMAT (exact template) → STORYBOARD / VIDEO-PROMPT / POST-PACK commands → FINAL QUALITY-CONTROL CHECKLIST (silent) → BEGIN NOW (generate exactly 10/20 topics immediately).
3. **Command language** the user types after setup: bare number `X` = generate X new ideas; `NEXT X` = continue registry; `PICK X` = lock topic; `STORYBOARD X`; `VIDEO PROMPT X`; `POST PACK X`; `FULL PACK X`; `COMPLETE PACKAGE`; `TXT FILE`.
4. Heavy negative constraints (`STRICT NEGATIVE PROMPT` / `MASTER NEGATIVE CONSTRAINTS` lists), variable/rotation banks to prevent repetition, Tier-1 audience targeting (USA/UK/Canada/Australia), `do not explain, do not ask questions — execute` directives.
5. Topic output template fields: TITLE, CORE CONCEPT, MAIN CHARACTERS, LOCATION, 0–3s HOOK, ESCALATION, REVEAL/PAYOFF, VIRAL SCORE (/100).
6. **30-second Seedance format:** ENGINE IDENTITY → CORE CONTENT DNA → PERMANENT SERIES IDENTITY (numbered locks) → EPISODE VARIABLES → CHARACTER SYSTEM + LOCK → realism locks → STORY ENGINE (`HOOK → CONTEXT → SOCIAL PRESSURE → ESCALATION → INFORMATION SHIFT → REVEAL → CONSEQUENCE`) → VIRAL RETENTION ENGINE → DEFAULT VIDEO SPEC (30s, 9:16) → CAMERA GRAMMAR / LIGHTING / PERFORMANCE / DIALOGUE / AUDIO → PHYSICAL CAUSE-AND-EFFECT + CONTINUITY LOCK → TOPIC DISCOVERY MODE → QUALITY CONTROL → SELECTION MODE → FULL VIDEO PROMPT GENERATION MODE → **ABSOLUTE SINGLE-PARAGRAPH RULE: one paragraph, 3,000–5,000 characters, no line breaks, no bullets, no headings inside the prompt.**
7. Granular continuity systems for series: state checkpoints per clip, anatomy continuity locks, mandatory physical action order (e.g. 10-stage painting order), micro-cut editing maps, CapCut assembly guides, social-media SEO systems.

### 2.2 Realism / negative-constraint examples (reuse verbatim style)
- `❗ ABSOLUTE REALISM RULES (NON-NEGOTIABLE): Looks like a random phone video. Handheld, one hand only. Weak camera angle. Slight blur, imperfect focus. Late camera reactions REQUIRED. Shaky framing. Awkward timing. No cinematic movement. No slow motion. No music. No dramatic lighting. No staged positioning. No influencer behavior.`
- `🚫 NO reaction before FACE-TO-FACE` / `🚫 NO MUSIC, 🚫 NO EFFECTS` / `NEVER ALLOW: Extra fingers. Six-finger hands. Character morphing. Camera zoom. Camera pan. Camera shake… CGI hands. Plastic skin… AI watermark…`

Mouth drops OPEN but SILENT. Jaw locks. Body freezes completely. Camera reacts late: first 0.5 sec her face partially missed, then sudden jerky correction.`

## 9. 15s / 30s BULK PRODUCTION PLAN (consistent results, old-age audience)

**Consistency engine (same character/scene across a bulk batch):**
1. **Character Lock Sheet (LOCKED):** for each series, fix: breed, age, sex, coat color/markings, collar type/color, size/weight, owner's appearance (age, clothes). Write once, paste into every prompt's `(LOCKED)` block.
2. **World Lock (LOCKED):** fixed location set per series (e.g. "small suburban house, golden-hour, wooden front porch"), camera grammar (handheld smartphone, 9:16), lighting mood.
3. **Seed strategy:** generate ONE master image first (character + setting), reuse as image-to-video input / character reference for every clip in the batch.
4. **Episode variables (CHANGEABLE):** only the micro-story changes per video: [THE WAIT], [THE RECOGNITION], [THE HUG]. Template stays identical.
5. **Batch workflow:** `TOPIC DISCOVERY` (20 scored topics) → `PICK X` → `STORYBOARD X` (scene beats with timestamps) → `VIDEO PROMPT X` (single-paragraph 3,000–5,000 chars for 30s; tighter 1,500–2,000 for 15s) → `POST PACK X` (title + description + hashtags + pinned comment).
6. **Old-age audience adaptations:** slower scene changes (max 4–5 beats per 30s), large burned-in text (min 1/8 screen height, high contrast), one clear emotion per video, warm color grade, no rapid cuts, English captions always, nostalgic props (porch, letters, old photos), American names/settings.

**15-second structure:** 0–3s HOOK (peak emotion or anticipation) → 3–10s ESCALATION (one turn) → 10–15s PAYOFF (hug/recognition) + text punchline.
**30-second structure:** 0–3s HOOK → 3–8s CONTEXT → 8–15s SOCIAL PRESSURE/TENSION → 15–22s INFORMATION SHIFT → 22–27s REVEAL → 27–30s CONSEQUENCE (hug) + end card text.

## 11. YOUTUBE AUTOMATION MASTERY (learned from @wizofYT "Andrew" — 22.6K subs — and @editarick "Rick Edição" — 5.81K subs; researched 2026-09-18)

### 11.1 Trust score = the #1 technical unlock
- Aged/warmed Google accounts + proxies + Multilogin/antidetect profiles + strict separation (channels, AdSense, setups never linked) → avoids domino termination.
- "Trusted"/pre-monetized channels monetize in ~18 days. New channels: 1 video/day until monetized, then scale to 5/day.

### 11.2 Niche selection
- **Old audiences (60+, US, TV) = the monetization sweet spot:** high RPM ($5 → $8.40 → $28–$50 with premium-advertiser topics like finance/real estate/insurance), loyal, buy ebooks/PDFs "with fury".
- **Rick's niche-validation checklist (quantitative):** (1) videos get consistent average views, not random outliers; (2) banger-to-flop ratio 7:1 minimum, 10:1 ideal; (3) has competitors; (4) at least +2 competitors doing well; (5) CRUCIAL: zero failing competitors using the same recipe/quality; (6) niche in EMERGENCE phase (not pioneer, not mass adoption, not saturated — early first movers win); (7) the recipe/format is clear and you know WHY it works and WHO the audience is; (8) monetizable.
- Evergreen > trends. Breaking-news clickbait = audience fatigue + YouTube "inauthentic content" risk.

### 11.3 Ideation: outlier/parasite method, niche bending, cross-niche arbitrage
- Find proven topics/creators, repackage the angle for a new audience ("parasite/topic-transfer").
- **Niche bending / cross-niche arbitrage:** don't copy one channel — borrow the thumbnail style from one proven winner and the title/angle style from another; break the copycat cycle.
- Niche down hard ("Amish + gardening", not "gardening"). Find incumbents doing it wrong (too short for the audience/device) and go LONGER.

### 11.4 Volume + speed (fishnet strategy)
- Test many hypotheses, kill losers fast, scale winners. One winner recoups all failures. 10–20x ROI on cheap videos.
- Cost benchmarks: ~$3–4/video (100% AI images) up to ~$35–40/video. ~95–99% margins are normal.

### 11.5 Packaging: titles + thumbnails
- Better titles on the SAME topic than competitors = 3–5x views.
- **Anti-design thumbnails:** one visual anchor, instant processing, no collage/chaos; "ugly native" style can beat polished; confusion kills clicks more than boredom.
- The video MUST confirm the thumbnail (audience satisfaction; avoids inauthentic-content strikes).

### 11.6 Retention engineering
- Study AVD (average view duration) graphs + comments yourself; chaptering = re-entry points; cold cinematic anti-hooks (sensory scene → question loop in first 20 seconds, e.g. "Midnight in California…").
- Dopamine via numbers/charts/facts for old audiences; dual-intent scripts (serve two viewer types, never fully kill the myth → comments + watch time); session-time optimization — lean-back TV content, autoplay chains, never end the session or mislead.

### 11.7 Monetization beyond AdSense (case-study numbers)
- $17 PDF via in-video CTA + description on a REAL domain (free domains kill trust).
- AI-generated ebook funnel: $160K revenue / $140K in 30 days / $24K in 7 days via Gumroad + native soft-sell + 5-star review protection + Amazon KDP physical; email list of 3,000 buyers for cross-sell.
- ClickBank affiliates for old people (health/insurance/financial): math example 4M views × 0.7% CTR × 1–2% conversion → $20–50K/mo.
- Selling channels: $30K exits after ~2 months.
- Reference: WW2-tales-style slideshow channel did ~$113K AdSense + $17K digital products in ONE month (Sept 2025); AI-avatar channel did $273K in June 2026 at ~95% margin.

### 11.8 Scaling: systems, not tools
- SOPs for everything; hire channel managers (performance owners), incentivize on views not money; founder keeps only niche selection, ideation, packaging; VAs handle production. "1 killer with AI = 5 people."
- "Better $10K from 10 channels than $100K from one." Launch a 2nd channel in the same niche BEFORE competitors do. Use YouTube's Collab feature to be your own competitor. Translation scaling into German/French (old, high-RPM audiences).
- Mine comments (extension → CSV → AI) for ranked content ideas; bi-weekly analysis across all channels, double down on outliers.

### 11.9 Mindset
- Imperfect action beats analysis paralysis. Volume is the game. Never copy blindly — bring your own unfair advantage. Play for winning, not to prevent losing. Reinvest; don't lifestyle-spend ("no free money" phase).

**Script → Assets → Shot list/Prompts → Generation.** "Assets first, prompts second, generation last — generating before assets are locked means the model has nothing fixed to hold onto." Script = build list (every INT./EXT. = location to build; every character name = sheet needed). **Math: one 15s Seedance generation = exactly one shot** (2-min film ≈ 8 shots) — script hands you shot count before spending a credit. "Story first, prompts second — that order is the whole method."

### 12.2 Character consistency system (the bulk-production key)
1. **3-view grey sheet** (front/back/close-up) per character — this is what holds face+outfit+proportions across dozens of shots. Generate in Soul Cinema (16:9, 2K, batch-and-pick — cheap, ~8 gens/credit).
2. **REJECT TEST: screen for LIGHTING not likeness** — soft near-shadowless, no hair glare, visible catchlights. "A cinematic AI video is only as good as the reference photo behind it."
3. **ONE face per sheet** — erase extra faces from full-body shots (prevents face drift).
4. Lock as Higgsfield **Element with @name** (@eduardo, @loc_cabin…) — prompts auto-pull matching inputs; Claude references assets by name.
5. Locations: always generate at **"3/4 angle"** (two walls visible = real depth — "cheapest fix for depth"); name tones/weather/time for mood.
6. Mid-story **re-sheet on wardrobe change**; reverse-angle environment refs for dialogue coverage; **180° rule** for geography.
7. COMPATIBILITY TEST: hero + location in a quick test generation BEFORE locking the rest.

### 12.3 Prompt anatomy (working template for Seedance)
Master Style block → @tagged ACTIVE REFERENCES ("100% matches the reference") → SCENE CONTEXT → LOCATION MAP → FIRST FRAME/BLOCKING → FORMAT MODE ("sequence of cuts, no timecodes — camera does not cut on its own") → numbered CUTS (shot size + FOV: MS 47°, MCU 29°, OTS, 63° handheld) → OPTICS → CAMERA (1–2cm handheld breath, chest height) → ACTION (timed ①②③ beats) → PERFORMANCE (muscle-level acting, pore-level skin, micro-movement) → PHYSICS (objects keep identity, move only when hands move them) → LIGHTING (Kelvin values: 3200K practical vs 5600K sun, volumetric god rays) → AUDIO (named dialogue lines) → STYLE → POSITIVE LOCKS.
Master Style block example: "8K IMAX. Photorealistic — no 3D render, no game engine. Cinematography: Lubezki × Deakins. Natural light only — contre-jour, camera on shadow side. Color 60:30:10. 180° shutter. Pore-level skin. Micro-pauses, precise eye-line, wet living eyes. Gravity/inertia respected. Rule of thirds + golden ratio. No identity drift. 24fps. Keep ONE connected shotlist: style prefix glued to every prompt + named prompts (1a, 1b, 2a) so you edit like an editor.

### 12.5 Iteration doctrine
Run → critique → plain-language notes to Claude → Claude rewrites at cut level → re-run. Combine best parts across batches. Isolate-and-fix (VO separately — never re-roll the whole shot for a voice issue). Correct ONE variable at a time. "Treat the model like a crew member, not a slot machine."

### 12.6 Diagnostics (when generations fail)
"When every take in a batch of four comes back wrong, the seed isn't the problem — the prompt is." Read specific tells: extra chair = prompt didn't lock room contents; boring angles/dead eyes = prompt described setting, not performance. REWRITE, don't re-roll. **NEVER write negatives** ("he's not crying" → model reads "crying") — positive phrasing only. Name techniques, not moods ("add a speed ramp", not "add more drama"). "Basic isn't broken — it's the signal to stop tuning emotion and start tuning camera."

### 12.7 Camera/motion vocabulary
Dutch angle (psychological trap — character feels trapped before a word is spoken); whip pan (state swing DURATION + what it SETTLES on; open and close on same frame size); speed ramp (speed change INSIDE the shot); match cut (invisible handoff); crash zoom; POV simplification; locked-off vs handheld; flares/fog for atmosphere; text props (give EXACT words word-for-word, hold shot long enough to read); aging for flashbacks (rewrite the locked sheet, don't regenerate; props sell era fastest).

### 12.8 Video-to-video (for real-footage hybrid)
Real clip in + one-sentence change = same shot out; motion/face/camera untouched. **"ALWAYS KEEP AN ANCHOR"** — something stays genuinely real (hands, face); change everything and the brain smells fake. @source formula: "@source: Original clip — [description]. Subject, face, [elements] — preserve exactly. Replace [background] only. Photoreal. 16:9. 6s. Filmic look — [grade]."

### 12.9 Voice
Seedance auto-generates a unique voice per character sheet, tone matched to looks — **lock visuals = lock voice**, no separate voice step. VO fixes = delivery directions (micro-pauses, trembling voice), not camera blocking; isolate the VO read, fix separately.

### 12.10 Bulk/series pipeline (faceless automation)
One Claude chat (MCP + skill): single sentence → full 10-min video → cloned voice → second-language translation → thumbnails in minutes → **20 SHORTS IN ONE CLICK** → 30-day content plan. No separate editing software, no manual handoffs. Monetization rule: "YouTube doesn't check whether content was AI-generated — it checks whether it's valuable to watch." BORROW THE FORMAT, NOT THE CONTENT (avoids reused-content strikes).

### 12.11 Preflight gates (before any generation)
- Every returning visual needs ONE approved reference + ONE stable name — "if you can't point to both, the scene isn't ready."
- 180° test: "if the camera turned 180° now, which approved reference describes the frame? If none — geography isn't locked."
- Dependency list first: one row per returning visual (stable name + approved reference + dependent scenes).

### 12.12 Directing principle
"Directing first, prompting second — is the actual edge." Decide what every shot should FEEL like before generating; camera language scripted on purpose; emotional beats mapped before generating; color curated shot to shot. "Technique without emotional arc is a demo reel, not a film."

## 14. PACKAGING SCIENCE (titles, thumbnails, outliers, niche discovery — research 2026-09-18)

### 14.1 Title psychology
- **The only 3 clickworthy emotions:** curiosity, fear, desire (Jake Thomas, Creator Hooks, 100M+ views). Write the title BEFORE recording — forces the video to deliver on a real promise. Clickbait (teasing what the video doesn't deliver) destroys trust.
- **2026 viral structure:** Emotional Trigger → Curiosity Gap → Transformation/Payoff. Ex: "I Fixed My Credit Score in 45 Days — Here's the Real Story".
- **Length:** hard ceiling 100 chars; sweet spot 40–55 chars / 7–11 words (full title visible on mobile); front-load the keyword. Peer-reviewed study (Kawata et al. 2024, 12,466 videos): bell-shaped views-vs-length curve; character-count matters more than word count.
- **Numbers:** specific beats round ("$4,237 in 14 days" > "$10K"); odd/specific numbers (7, 17, 23) outperform. Brackets frame a sub-promise: "(Shocking Results)". Power words: secret, hidden, mistake, warning, finally, proven, exposed, destroyed, genius. Max 1–2 ALL-CAPS words, max 1–2 emojis.
- **Browse vs Search rule:** browse/suggested traffic (>80% of viral traffic) wants emotional curiosity titles; search traffic wants keyword-led titles. Choose per the video's primary traffic source.

**15 proven title templates:**
1. Curiosity Gap: `[Unexpected outcome] — and [surprising detail] is why.`
2. Bold Claim: `I [specific achievement] in [timeframe] using [method].`
3. Contrarian: `[Common belief] is wrong. Here's what actually works.`
4. "Don't" (loss aversion): `Don't [common action] until you [prerequisite].`
5. Secret: `The [hidden/secret] [thing] that [impressive result].`
6. Shocking Stat: `[N]% of [group] [surprising behavior]. Here's what the others know.`
7. "If You" qualifier: `If you [specific situation], this is [what you need].`
8. Mistake: `I [mistake] that [cost]. Here's what I learned.`
9. Question (never yes/no): `[Question the viewer can't answer confidently]?`
10. Proof + objection kill: `[Concrete result]. No [common excuse]. Here's exactly how.`
11. Comparison: `[Option A] vs. [Option B]: [what you'll discover].`
12. This vs. That: `[What most people do] vs. [what actually works].`
13. Listicle: `[Number] [things] that [achieve desired outcome].`
14. Authority: `As someone who [credential], here's [insight].`
15. Storytelling open: `[Time/place], I [unexpected situation]. [Cliffhanger].`

**10-title-variants SOP:** pick 3–4 patterns spanning intents (curiosity, contrarian, number/outcome, question); generate 10–20 options; score each 0–10 on curiosity gap, emotion trigger, specificity + deliverability yes/no; kill any failing deliverability; ship top pick; use Test & Compare or swap after 48h if CTR < niche benchmark.

### 14.2 Thumbnail design
- **3-element rule:** at mobile size, max 3 elements — one dominant subject + one emotion/facial cue + 3–6 words of text. Every extra object is clutter.
- **Faces:** humans stop for faces, scroll past neutral ones. Amplify emotion ~200% beyond natural (shock, confusion, intense joy). Close-ups > full-body. Before/after contrast beats blank portraits.
- **Contrast/color:** design around YouTube's UI (white/black/red). High-contrast pairs: yellow↔purple, blue↔orange, red↔neutral. Neon glows (cyan, electric purple) + deep shadows. **Squint test:** blur eyes — whatever stays recognizable is the visual anchor. Grayscale test for color-blind safety (~8% of men).
- **Text:** 2–4 words sweet spot (3 max for 10%-CTR blueprints). Thumbnail intrigues, title explains — **never repeat the title; complement it** ("I Quit My Job for YouTube" + "Basically Cheating").
- **Common mistakes:** repeating title, collage clutter, low contrast, neutral faces, tiny text, ignoring Shorts-feed cropping, never testing (tested thumbnails → ~2.8× higher watch time, vidIQ).
- **Anti-design vs polished:** anti-design wins in raw/personal/journey niches (polish reads as fake) and scroll feeds (pattern-interrupt); polished wins where the promise is expertise/premium (finance, filmmaking, tech). Rule: match design fidelity to what the audience already trusts in that niche, then add tension via emotion/contrast/unanswered question.

### 14.3 Title–thumbnail fit (one unit)
- **Verification loop:** viewers read title → look back at thumbnail for subconscious confirmation. Mismatch = scroll past.
- **Division of labor:** thumbnail = visual tension, title = intellectual tension. Neither should tell the full story alone.
- **Promise and Proof:** one coherent promise (title) + one visual proof (thumbnail), together withholding the payoff. Packaging is designed FIRST; the video must deliver (inauthentic-content risk).

### 14.4 Outlier analysis SOP
- **Definition:** views massively exceeding channel baseline — measured by outlier score/multiplier (views vs channel average) and velocity (VPH, views per hour). VPH catches momentum; multiplier catches structural over-performance.
- **Steps:** (1) build 10–20 competitor channel list (incl. 2–3 small winners); (2) filter window last 30–90 days, match format; (3) scan sorted by outlier score + VPH, not raw views; (4) rule of thumb: views ≥ ~10× channel's typical views = log it; (5) log in swipe file: channel, subs, title, thumbnail text+layout, views, date, VPH, multiplier, one-line angle, format, hook (first 30s), YOUR one-line hypothesis why it won; (6) weekly pattern pass: same title structure 3+ times? same thumbnail composition? (7) deep pass: transcript → map hook → open loops → re-hooks, chapters/re-entry points; (8) generate, don't copy — borrow format, never content.
- **Tools:** 1of10 (outlier dashboard, multiplier, VPH), vidIQ Outliers (keyword-based, filters), ViewStats (free), SubSub/open.subsub.io (channel benchmarking), YouTube Data API v3 for automated daily tracking, Google Sheets/Apps Script hourly trackers.

### 14.5 Niche discovery methods
1. **Niche bending:** proven FORMAT + new MARKET = new niche. Copying a niche fails; bending a format works.
2. **Adjacent-niche mapping:** same viewer, different problem. "Niche T": go a mile deep (identity) or a mile wide (mass appeal) — "you don't win by being the most informative, you win by being the most memorable."
3. **Comment-section mining:** extension → CSV → AI workflow for ranked content requests; reuse audience's verbatim language in titles.
4. **"Channels doing it wrong" gaps:** weak packaging (generic titles, no thumbnails, wrong length for audience/device) + proven demand = fastest entry.
5. **Language arbitrage:** non-English = ~10× less competition; German = top RPM (old, wealthy); Spanish = scale.
6. **Emergence-phase targeting:** some competitors doing well, not saturated. Quantitative screen: consistent averages, ≥7:1 banger-to-flop, 2+ thriving competitors, zero failing same-recipe competitors.
- **Validation checklist:** demand (sub-100K channels getting views), moderate competition, profitability (high-RPM adjacency or product path), evergreen base, self-check (can you make 10–20 test videos without burnout?).

### 14.6 Angle transfer framework (worked)
1. Find outlier in niche A; log angle in one sentence. Ex: "I Asked 100 Millionaires How They Got Rich" — angle = crowdsourced truth extraction.
2. Extract skeleton: `[I asked [N] [authority group] [secret question]]`.
3. Map onto niche B: "I Asked 100 Vets What They Feed Their Own Dogs (Their Answers Shocked Me)" + thumbnail "DON'T FEED THIS".
4. Adjust emotion dial: finance = desire/wealth; pet = fear/love.
5. Rewrite in own words (reused-content safety). 6. Keep the proof format (genuinely deliver N sources). 7. Test 2–3 transplants; when one hits, reuse structure up to ~7×.
- Second example: productivity "I Tested 23 AI Note-Taking Apps for 30 Days. Here's the Winner" → pet niche "I Tested 23 'Calming' Dog Products for 30 Days. Only 1 Actually Worked".

### 14.7 Hashtags & description SEO (2026)
- **Title + thumbnail + watch behavior >> hashtags.** Hashtags are a minor aid, never a growth lever.
- **Shorts:** `#Shorts` + 1–2 niche tags + 1 trending (3–4 total). Shorts distribute on completion rate + swipe-away rate, not keywords — first 1–2 seconds must stop the swipe; keep tight and loopable.
- **Long-form:** 3–5 hashtags at description END; mix broad/mid/specific; cover related terms the title missed. Backend tags: 5–8 relevant (500 chars allowed); 20+ = spammy.
- **Hard limits:** >15 hashtags = ALL ignored; first 3 show above title; ~60 title chars visible on mobile; ~120 description chars above the fold; chapters need ≥3, first at 0:00, each ≥10s.
- **Description structure:** line 1–2 = hook + primary keyword → context → links/CTAs → hashtags last.

### 14.8 Daily ideation system (30-min routine)
- **0:00–10:00 Outlier sweep:** 1of10/vidIQ/ViewStats, niche keyword, sort by outlier score + VPH, last 7 days → capture 5–10 into swipe file.
- **10:00–18:00 Pattern extraction:** compare vs log; note 2–3 patterns; mine top 1–2 outliers' comments for verbatim audience language.
- **18:00–26:00 Angle generation:** 10 titles — 2–3 patterns × 3 variants + 2–3 angle transfers from other niches; spread across patterns.
- **26:00–30:00 Score and queue:** 0–10 on proven angle / audience fit / deliverability → /30; keep top 3; kill <18.
- **Weekly (10 min):** cross-week patterns; your uploads vs borrowed angles. **Swipe file rule:** every entry needs outlier score + your hypothesis, or it's dead weight. **Monthly:** niche-health check (banger-to-flop, new competitors, VPH trends) → double down, bend adjacent, or launch 2nd channel.

### 15.9 Failure handling: diagnose → change ONE variable → retry
- **Retention curve shapes:** THE CLIFF (collapse first 15–30s) = hook doesn't deliver on promise (most common) → rewrite hook only. THE SLIDE (steady decline) = answered too early then rambled → restructure pacing, move payoff later. THE PLATEAU (early drop then flat) = GOOD, right audience stayed → fix packaging, not content. THE SPIKE (curve rises) = rewatch moment → put it at the FRONT of the next video.
- **Reach tab benchmarks:** CTR < 2% with healthy impressions = packaging problem → new thumbnail/title, recheck in 3 days ("doubles reach more often than any other single change"). AVD < 25–30% = hook/pacing problem; 35–45% decent; 50%+ strong. Compare vs YOUR OWN last 20–30 uploads, not platform averages. Shorts: 70%+ retention at 30s = strong; <60% = stalls. Onscreen text in hook ≈ +18% watch time; pattern interrupt in first 5s ≈ +23% retention.
- **One-variable retry loop:** diagnose (curve + CTR + AVD → one root cause) → change exactly ONE variable (thumbnail/title OR hook OR pacing cut OR topic angle) → packaging failure → swap on SAME video (Test & Compare crowns highest watch time, not clicks), wait 3–7 days; content failure → remake with single fix (never reupload identical) → log experiment → kill losers, scale winners.
- **<10-min flop checklist:** curve shape identified? CTR vs baseline? AVD at 30s? traffic sources (Browse low + impressions high = thumbnail failed)? comments scanned for complaint pattern? ONE variable selected? fix applied + 3–7 day wait? result logged? Still flat after 2 cycles → kill the format, not the channel.
- **Retention repair:** 30s hook delivering on title; re-hooks + pattern interrupts every 60–90s; highest-ROI edit = cut your most boring 30 seconds; chapters help long videos, hurt short ones.

## 16. SCRIPTING SCIENCE (retention, hooks, pacing, WPM, trust, comments, conversion — research 2026-09-18)

### 16.1 Calibration numbers
- Average retention 23.7%; only 1 in 6 videos passes 50% (Retention Rabbit 2025). Targets: <5 min → 50–60%; 5–10 min → 50%+; 10+ min → 40–60%; Shorts → 70%+.
- +10 pts retention ≈ +25% more impressions. 55% of viewers gone by 60s; 33%+ leave in first 30s; stay/leave decision ≈ 8 seconds (2–3s for Shorts). **70% retention at 30s predicts promotion.** Mid-video danger zone: 55–65% mark.

### 16.2 Hook: 0:00–0:30 anatomy
- **Faceless hook stack:** on-screen text, pattern interrupt, direct promise, visual velocity. On-screen text in hook = +18% watch time; pattern interrupt in first 5s = +23% retention; "hey guys, welcome back" costs ~20% immediately; establish value within 7 seconds.
- **0:00–0:05 pattern interrupt** (unexpected claim, contrarian frame, visual surprise) → **0:05–0:15 payoff promise** (specific: "This thumbnail change took a video from 400 to 40,000 views" beats "thumbnails matter") → **0:15–0:30 proof/credibility + open loop**.
- **Hook density rule:** minimum 3 retention mechanisms in first 30s (hook + open loop + pattern interrupt); Shorts: 2 in first 3s + 1 in 3–15s. Brain sequence: reptilian (0–3s) → limbic (3–15s) → neocortex (15s+).
- **6 hook formulas:** (1) Contradiction: "This is the wrong way — and it's how everyone was taught." (2) Stake setup: "Most creators lose 70% of their audience in 60 seconds. You don't have to." (3) Specific number: "Forty percent was gone within a year, and nobody noticed." (4) Pattern interrupt before first word. (5) Direct challenge: "Watch 30 seconds and tell me I'm wrong." (6) What-I-learned: "I spent 6 months — here's the one thing that mattered."
- **Loss framing beats gain framing.** Every hook = 3 layers: spoken line + text overlay (sound-off) + visual open.
- **The confirmation second:** intro's real job = confirm the title/thumbnail promise in 30s. All three must match in promise type, intensity, topic. First-30s cliff = promise never confirmed.
- **Title→hook template:** [0:00–0:05] say AND show title's subject → [0:05–0:15] state specific payoff → [0:15–0:30] one proof line + first open loop.

### 16.3 Retention engineering
- **Open loops = #1 mechanism.** Before closing a block, plant a reason to stay: "…that's why the first 15 seconds decide everything. But a great hook makes the second problem worse — here's how you keep it." Reorderable blocks = a list (viewers skip); causal blocks = a chain (unskippable). Every loop must be paid off later.
- **Re-hook cadence:** mini-hook at every section transition ("That was important, but without this next one the magic is lost"); re-hook every 2 minutes ("But here's where it gets interesting…"); no section > 2 min without payoff/data/energy shift; one retention trigger (question, reveal, contradiction, callback) per ~90s; new visual every 10–20s; explicit `[PAUSE: 2 seconds]` cues for emotional beats.
- **Payoff pacing:** 2–5 min → 1–2 payoffs (surface); 6–12 min → 3–5 (detailed + examples); 13+ min → 5–8 (deep + stories + steps).
- **Mid-video armor (min 4–7, 55–65% dip):** pacing variety (calm + bursts); "for you" pivot ("If you're only here for the ending, stay 20 more seconds"); tactical takeaways rewarding watch-through.
- **Ending ("free chocolate" principle):** strong outro → retention, likes, comments, rewatches. Wrap cleanly, summarize, remind of pain solved. Shares happen at the final moment → fuels algorithm.

### 16.4 Storytelling structures (faceless)
- **3-Act documentary:** cold-open hook → reconstruction → moment of collapse → autopsy (root cause) → lesson. Failure-as-mystery: known outcome + unknown cause = strongest hook.
- **Hero's Journey (8–20 min):** ordinary world → inciting incident → trials (midpoint gut-punch) → transformation → return with the "elixir" (emotional truth). For animal stories: dog/shelter/owner = hero; elixir = "loyalty outlasts everything". End echoing the opening image.
- **"But–Therefore" chain:** replace "and then… and then…" with "but… therefore…". "The soldier left. Therefore the dog waited at the gate every night. But the shelter only gives him 24 hours…" — a chain is unskippable, a list invites skipping.
- **Loopable Shorts (15–25s sweet spot):** peak emotion from frame 1; end on the SAME visual that opens; optionally leave one unresolved loop pulling back to start. Since March 2025 each loop = a new view; >100% average watch = extreme satisfaction; 70%+ completion ≈ 30% more promotion. One hook, one idea, one turn, one payoff.
- **Binge architecture:** Shorts + long-form combined grow 41% faster. Topic clusters, playlists as mini binge funnels, end screens to next most relevant video. End every video teasing the specific next video by name.

### 16.5 Pacing: WPM targets
- Shorts (60s): 130–150 WPM (max ~150 words; >160 guarantees overrun). Standard long-form (8–20 min): 130–150 (AI sweet spot), up to 170. Tutorials: ~120 with 15% B-roll buffer. **Older audience (55–65+): 110–130** — deliberately slower, repeat main points.
- Rule: **word count × 0.4 = seconds of video.** Write full script first, then time it (scripttimer.io / read-aloud); never estimate from outline.
- **Older-audience adjustments:** slower read + repetition of main points; short sentences, simple words; captions/subtitles non-negotiable (hearing decline + TV/tablet viewing); lean-back TV favors 8–20 min slower narratives — dopamine from story beats and facts, not cuts.
- **Silence (write it in, don't leave it to chance):** pause after a key statement cues importance and aids processing; beat of quiet before a reveal builds anticipation; micro-pauses 50–300ms (7–12/min ≈ 88% completion vs 34% for <2/min — directional). In AI voiceover: script `[PAUSE: 2 seconds]` before reveals, micro-pauses after names/numbers. Slow wins: emotional climaxes, tutorials, documentaries, senior audiences, lean-back TV. Removing every pause reduces what the audience takes away.
- **For 15s/30s emotional Shorts:** fast hook (0–3s), then deliberate 1–2s pause at the reunion/hug moment — a retention feature, not dead air.

### 16.6 Script testing (pre-production checklist)
Every script must pass: hook earns 5s; first 5s SAY title's subject + SHOW thumbnail's subject (mute test understandable?); promise specific/measurable, value clear by 0:30; roadmap after hook; open loop at every transition; ≥1 trigger per 90s; no section >2 min without payoff; mid-video variety; intro ≤45s; ≥2 curiosity gaps early; zero filler ("without further ado", "let's dive in", "hey guys"); word count matches WPM target; CTA specific with a reason; visual cues every 10–20s.
- **3 tests:** (1) Read-aloud "mouth edit" with stopwatch — AI scripts fail here; goal: "sound like telling a story, not reading." (2) The bus test — hook alone must earn a stranger's attention. (3) Title–thumbnail–promise alignment gate — mismatch = CTR without retention = algorithm punishes the channel.
- **Retention prediction:** score hook density, loop density, interrupt cadence, callbacks, payoff spacing; reject scripts in channel's bottom-quartile predicted AVD.
- **A/B:** YouTube "Test & Compare" (up to 3 titles/thumbnails, winner = watch-time share). Hook prompt pattern: "Give me 5 different 15-second opening hooks: 1) Shocking Statistic, 2) Common Mistake, 3) Direct Question, 4) Story/Experience, 5) Inverted Result."

### 16.7 Trust-building (faceless-specific)
- **Specificity = #1 trust signal.** "He waited 438 days at the same bus stop" beats "he waited a long time." Vague promises read as clickbait.
- **Admit limits openly.** Corrections, updates, "I don't know" > false certainty. Pinned clarification comment = documented trust signal.
- **Proof elements (show, don't claim):** charts, demonstrations, citations — on screen at the moment the claim is made; the visual carries what a face would.
- **Give the narrator a POV.** 5 rules for faceless 2026: an opinion viewers remember; information → show (characters + conflict); visual identity recognizable with sound off; writing IS the personality; real expertise + unique format.
- **Consistency = credibility:** same voice, same visual style, same upload rhythm = proof of life. Disclose AI assistance plainly (YouTube's altered-content label does not limit reach or monetization eligibility). July 15, 2025 "inauthentic content" policy targets superficial differences/reused narration/no human creative input — defense = original commentary, research, narrative depth in every script.
- **Anti-patterns:** over-promising thumbnails, buried value, info-dumping (10 points when 3 would be memorable).

### 16.8 Comment-baiting (ethical) + comment mining
- **Pinned-comment formulas (reply lift):** polarizing question +30–38%; timestamp challenge ("Find the Easter egg at 3:15") +20–37%; micro-poll +25–30%; Q&A tied to a moment ("At 4:32 — too far or totally fair?") +20–30%; prediction before reveal +15–25%; viewer-to-viewer debate = longest threads; co-creation ask ("one topic nobody covers — best gets a shoutout") = quality + repeat visitors; critic pin with response = thread depth + trust. Pin IMMEDIATELY after upload.
- **In-video triggers:** open-ended questions (never yes/no); "What would you do?" moral dilemmas ("He had 24 hours left and no one wanted him. What would you have done?"); prediction before reveal in first 30s; mild good-faith stance ("Senior dogs make better companions than puppies — fight me in the comments"); timestamp-linked questions pull viewers back = dwell + rewatch.
- **Reply strategy (first 2 hours critical):** reply to EVERY comment; heart thoughtful ones (notification brings them back); reply hierarchy: follow-up question > added value > acknowledgment > generic "Thanks!"; every reply invites another reply. >30% reply rate within 24h = 22% higher subscriber retention (Wistia 2024).
- **Comment-intel system:** pain points ("I've been trying to…", "nothing works for…") = search-intent gold, copy verbatim into titles; feature/topic requests = next video; 5+ people asking same question = that video doesn't exist yet, make it; competitor mentions = who viewers evaluate; user language = SEO language (harvest for titles/descriptions); first comments set the section's emotional tone — seed and shape them early.

### 16.9 Conversion (soft CTA placement)
- **Golden rule: ONE primary CTA per video.** 80% of content value-only; when you ask, ask for exactly one thing.
- **Choreography:** early CTA (first 15–30s, soft, <10 words: "The template I use is linked below") → mid-video CTA (30–70%, highest-converting — right after a payoff: "The exact checklist is linked below — it'll save you time"); affiliates = tool inside a utility story, not a pitch → close CTA (last 15–30s, direct: recap benefit → social proof → clear action).
- **Always-on layers:** description line 1 = benefit + link; pinned comment = link + one-sentence reason (~18% higher description CTR, vidIQ 2025); end screen = one logical next video.
- **Native embeds (anti-ad):** pain point → your resource as the solution; or speedrun a framework so fast they can't absorb it → free resource as implementation.
- **Shorts:** descriptions/comments NOT clickable — route via "link in bio"/"link on my channel"/companion long-form; Shorts CTA ultra-short, action-oriented.
- **Benchmarks:** in-video CTAs ≈ 380% higher CTR than sidebar (Kissmetrics); personalized CTAs ≈ +42% conversion; link-out referral avg ~0.7% of views, best ~4.4% (dated floor).
- **Older audience:** slow verbal CTAs, repeated once ("The link is in the description below — I'll say it again at the end"); no urgency tricks (fake countdowns destroy 60+ trust); codes read aloud AND pinned.
